# 进销存管理系统 VBA 完整版说明

本目录包含完整的进销存管理系统 VBA 脚本，覆盖了你要求的主要功能：

- 基础信息录入与去重
- 供应商/客户/商品下拉选择
- 入库单、销售单、退货单、报损单、报溢单保存
- 库存统计自动更新
- 成本均价计算
- 销售利润快照记录

## 文件说明

- `InventorySystem_Refined.bas`：当前完整 VBA 实现，适合直接导入 Excel VBA 编辑器
- `InventorySystem_Complete.bas`：早期完整版本，可作为参考
- `InventorySystem.bas`：早期基础骨架版本，可保留用于参考

## 导入步骤

1. 打开 Excel 文件（启用宏）
2. 按 `Alt + F11` 打开 VBA 编辑器
3. 右键 `VBAProject (你的文件名)`
4. 选择 `导入文件...`
5. 导入 `InventorySystem_Refined.bas`
6. 运行 `SetupWorkbook` 初始化工作簿结构
7. 再运行 `RunSystemSelfCheck` 检查工作表和数据表是否完整

## 关键入口

- `SetupWorkbook`：初始化所有工作表及数据表
- `ValidateAndAddProduct`：新增商品并校验重复
- `ValidateAndAddSupplier`：新增供应商并校验重复
- `ValidateAndAddCustomer`：新增客户并校验重复
- `SaveReceipt`：保存入库单
- `AddEntryRow`：在当前单据增加一行录入行
- `RemoveEntryRow`：删除当前单据最后一行录入行
- `PrintCurrentDocument`：打印预览当前单据
- `AutoFillReceiptUnits`：根据进货单商品名称自动带出单位
- `RefreshDropdownSources`：静默刷新商品、供应商、客户下拉源
- `SaveSales`：保存销售单
- `SaveSalesReturn`：保存销售退货单
- `SavePurchaseReturn`：保存进货退货单
- `SaveLoss`：保存报损单
- `SaveOverflow`：保存报溢单
- `RunSystemSelfCheck`：检查工作表和数据表是否完整
- `LoadDemoData`：一键载入演示商品、供应商、客户及全部交易单据

## 业务规则实现

### 1. 基础资料

- 名称必须从基础信息中选择，不能手动随意填写
- 商品、供应商、客户名称重复时禁止保存
- 商品名称选定后，可根据商品名称自动带出单位

### 2. 库存计算

- 库存数量 = 入库 - 销售 + 销售退货 - 进货退货 + 报溢 - 报损
- 成本均价按现有库存价和本次单据价格重新计算

### 3. 利润统计

- 销售保存时立即记录当时的销售单价和成本均价
- 之后即使基础信息改动，历史利润也保持不变

## 验证说明

当前代码文件已完成静态结构检查，但需要在本机 Excel 中完成最终验证：

1. 使用一个新的、已保存的 `.xlsm` 工作簿，不要使用 0 字节占位文件。
2. 导入 `InventorySystem_Complete.bas`。
3. 运行 `SetupWorkbook`。
4. 运行 `RunSystemSelfCheck`，看到“自检通过”后再录入基础资料。
5. 添加商品、供应商和客户后，分别测试入库、销售、销售退货、进货退货、报损和报溢。

如果 Excel 提示“变量未定义”：先在 VBAProject 中删除旧的 `InventorySystem`、`InventorySystem_Complete` 或同名旧模块，只保留当前导入的 `InventorySystem_Refined.bas`，然后执行“调试”→“编译 VBAProject”。旧模块中的按钮代码或 Office 常量可能仍会触发该错误。

## 最小可用录入顺序

1. 运行 `SetupWorkbook`，生成工作表、导航页和按钮。
2. 在“基础信息”中录入商品、供应商、客户。
3. 在“入库单”中填写供应商、商品、数量、单价，点击“保存”。
4. 在“销售单”中填写客户、商品、数量、销售单价，点击“保存”。
5. 按需录入销售退货、进货退货、报损、报溢。
6. 查看“库存统计”和“利润统计”，并运行“自检”。

## 单据界面操作

工作表“进货单”就是业务上的进货单；后台明细表名称仍为 `tbl_入库明细`，用于库存计算。供货单位使用基础信息供应商表的下拉列表，商品名称使用商品信息表的下拉列表；保存时还会再次校验，手工填写或粘贴不存在的供应商、商品会被拒绝。日期使用可选日期下拉列表，默认当天；单位不允许手工选择或修改，而是根据商品名称从商品基础信息自动带出。右侧按钮支持增加行数、减少行数和打印单据，进货单保存时会逐行写入明细表。若基础资料是直接粘贴到表格中的，可在导航页点击“刷新下拉”。

若要在选择商品后立即显示单位，请将 `receipt_sheet_event_code.txt` 中的代码复制到 VBA 编辑器左侧“Microsoft Excel 对象”下的“进货单”工作表代码页中。普通 `.bas` 模块不能接收工作表的 `Worksheet_Change` 事件。

如果直接在“基础信息”工作表中新增或修改商品、供应商、客户，请将 `master_data_sheet_event_code.txt` 中的代码复制到 VBA 编辑器左侧“Microsoft Excel 对象”下的“基础信息”工作表代码页中。这样基础资料一变化，所有下拉源会自动更新；也可以点击导航页的“刷新下拉”完成同样操作。

也可以先从“导航”工作表点击“载入演示数据”，一次性验证全部业务流程。演示数据现在包括 4 个商品、2 个供应商、2 个客户，以及多笔入库和销售记录，并覆盖销售退货、进货退货、报损和报溢。重复点击不会重复写入固定的演示单号。

运行 `SetupWorkbook` 后，系统会自动统一设置表头颜色、录入区底色、边框、列宽、数字格式、工作表标签颜色和按钮颜色。重新运行 `SetupWorkbook` 会重建初始化表格，因此正式数据录入前请先备份工作簿。
